## Como Publicar no GitHub

1. Cria um repositório novo no GitHub (ex: `corrupcao-suborno`).
2. Faz upload de **todos** os ficheiros desta pasta.
3. Vai a **Settings → Pages**.
4. Em Source escolhe a branch `main` e a pasta `/ (root)`.
5. Guarda. O site fica disponível em:
   `https://teu-utilizador.github.io/corrupcao-suborno/`

## Visualizar Localmente

Abre o ficheiro `index.html` no navegador.
